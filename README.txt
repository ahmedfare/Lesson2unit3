CODEUP — WEB APPLICATION COMMUNICATION LAB
Unit 3, Lesson 3-2 | with Ahmed Fareed

START:
1. Easiest: open CodeUp_Web_Communication_Lab_Standalone.html in Chrome or Edge.
2. For editing: open CodeUp_Communication_Lab/index.html. Keep styles.css and app.js in the same folder.
3. Works OFFLINE. No internet, API keys, server, database or external libraries required.

WHAT TO SHOW IN CLASS:
TOPIC 1: Client & Server — type a YouTube query, run the four-stage request/response animation.
TOPIC 2: HTTP & HTTPS — switch modes, send a sample login request, discuss TLS.
TOPIC 3: GET, POST & Status Codes — choose a request scenario, choose 200/404/500, inspect request/response.
TOPIC 4: API & JSON — call a simulated weather or school results API; validate and intentionally break JSON.
FINAL: Eight-question class challenge with feedback and score.

PRESENTATION:
Click Present or press F for fullscreen. Use left/right arrows to switch topics.
Click Teacher Tips to show Arabic prompts for classroom discussion.

IMPORTANT:
This is a TEACHING SIMULATION built with HTML, CSS and JavaScript only.
There is no actual backend or database, and the HTTPS mode does not implement real TLS encryption.
The example API host (codeup.example) is fictitious.

Edit code in VS Code if desired.
