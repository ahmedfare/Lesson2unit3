TOPIC 1 · REQUEST → RESPONSE

Who talks to whom?

The Client sends a request. The Server processes it and sends back a response.

💬
🎓 Teacher prompt: اسألهم: لما تكتب Python Tutorial على YouTube، مين بيبعت الطلب ومين بيرجع الفيديوهات؟ خلّي طالب يمثل الـClient وطالب يمثل الـServer.
💻

Client

The side that requests data or processing from a server.

Examples: Chrome browser · YouTube app · Weather app
🖥️

Server

The side that receives requests, processes them, and returns responses.

Examples: Web server · Application server

TOPIC 2 · COMMUNICATION RULES

HTTP or HTTPS?

A protocol is a set of rules that organizes communication between systems.

🔐
🎓 Teacher prompt: قول للطلبة: لو جهازين بيتكلموا من غير قواعد متفق عليها، هيفهموا بعض؟ وبعدين اسألهم: لو هنبعت Password، نختار HTTP ولا HTTPS؟
🔓

HTTP

HyperText Transfer Protocol — exchanges data between clients and servers.

Does not provide TLS encryption by itself.
🔒

HTTPS

HTTP Secure — HTTP communication protected with TLS encryption.

Helps protect data while it travels over the network.

TOPIC 3 · REQUEST METHODS & RESULTS

GET, POST and Status Codes

The method says what action is requested. The status code says what happened.

📡
🎓 Teacher prompt: قولهم GET يعني «هات بيانات»، وPOST يعني «دي بيانات عايزك تعالجها». بعدين اعمل خطأ 404 و500 وخليهم يخمنوا السبب.
🔍

GET Retrieve data

Ask the server for information.

Example: Search YouTube · View product details
📤

POST Submit data

Send data to the server for processing.

Example: Submit login · Sign-up form

TOPIC 4 · SOFTWARE COMMUNICATION

API and JSON

An API defines how software exchanges data. JSON is a format for representing that data.

🧩
🎓 Teacher prompt: اسألهم: تطبيق الطقس بيجيب الحرارة منين؟ بعد ما تجاوب، ورّيهم الـAPI Request والـJSON Response. خلي طالب يحدد الـKeys والـValues.
🔌

API

Application Programming Interface — lets different software systems request and exchange data.

Example: Weather app requests data from a weather service.
{ }

JSON

JavaScript Object Notation — a data format using names (keys) and values.

Example: { "name": "Adam", "grade": 95 }
